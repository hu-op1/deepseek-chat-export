feat: 本地 web 界面（概览 / 搜索 / 对话阅读器 / 星座图 / 主题图谱）

tools/serve.mjs 是零依赖的本地 HTTP 服务，只监听 127.0.0.1。

为什么要有服务而不是纯静态页：语义搜索要把查询词嵌入成向量，这需要 API Key。
静态文件里放 key 等于公开它；服务端只在内存里持有。

- 对话阅读器：把 48MB 的 JSON 渲染成可读对话。THINK 折叠（带耗时与字数）、
  TOOL_SEARCH/TOOL_OPEN 显示成搜索步骤、正文按 markdown 渲染、代码块独立配色。
  这是原来最大的缺口——备份下来根本没法读。
- 搜索：一句话语义检索，命中项带首条提问摘要和消息数，点进去看全文。
- 概览：每月对话数、各产物状态（备份/向量/星座图/图谱/标注进度）。
- 星座图与主题图谱：复用已有渲染器，加了一条返回导航。

lib/markdown.mjs 是安全优先的极简 markdown：先整体转义再套格式，
围栏代码块先抽出占位，避免里面的内容被行内规则改写。

tools/cluster.mjs：不用 LLM 的标签归并备用路线。840 个标签一次性丢给模型会 504，
分块归并要 5-12 分钟且中途失败前功尽弃；改成把标签嵌入后 k-means（35 秒、确定性），
每类用"离聚类中心最近的标签"命名。

修掉的三个 bug：
- 搜索结果标题全是"(无标题)"：nearest() 返回 {id, score, item}，取成了 hit.title
- 生成后的文件仍 404：getGraph/getAtlas 把"文件不存在"缓存死了
- 每月对话数用 toISOString（UTC）分桶，月初对话被算到上个月
